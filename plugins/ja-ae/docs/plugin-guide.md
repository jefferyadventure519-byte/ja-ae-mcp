# 第三方插件使用说明（给 Claude 和使用者）

这份说明来自一次实测：在一台电脑上把 1332 个第三方效果逐个加到图层上、读参数、渲染一帧看画面。下面是测出来的用法和坑。

## 0. 先看适用范围

- 测试环境：Windows 11，After Effects 2026（26.0），2026-10-13。
- 结论跟三样东西有关：AE 版本、插件版本、插件授权有没有生效。你的电脑只要有一样不同，结果就可能不同。
- 所以名单是「已知情况」，不是保证。**任何第三方效果用于交付前，都要渲染一帧看一眼。**

## 1. 用之前先查

1. 用 `ae_discover what:"effects"` 找效果。第三方效果带 `test` 字段，含义见返回里的 `fxTests.legend`。
2. 想知道这台电脑上哪些效果有已知问题：`ae_discover what:"effects" test:"issues"`。
3. 优先用 `test` 为 `ok` 的效果。`untested` 表示名单里没有（没测过的插件或版本），可以用，但要先出一帧检查。

| `test` | 含义 | 怎么办 |
|---|---|---|
| `ok` | 能加上、能出画面、参数可以用脚本改 | 正常用 |
| `preset` | 数值能改，「内容」改不了 | 见第 4 节 |
| `input` | 默认输出是纯色、空画面或提示文字 | 先给它指定输入（图层、文件、分析）或调参数，再出帧看 |
| `manual` | 要人在插件界面里操作 | 请使用者自己操作 |
| `wm` | 测试时输出带水印或未授权提示 | 交付前必须出帧检查；画面上有水印就不能用 |
| `wm_maybe` | 画面上有疑似水印的线条，没有确认 | 同上 |
| `noadd` | 测试时加不上 | 和测试相同的 AE 版本上会被拒绝；版本不同时会放行让它试 |
| `dialog` | 加上时弹出插件自己的窗口，脚本被挡住 | 会被拒绝。不要用 |
| `crash_add` / `crash_render` | 加上或渲染时 After Effects 崩溃 | 会被拒绝。不要用 |
| `timeout` | 90 秒渲染不出一帧 | 会被拒绝。不要用 |

被拒绝时 `ae_apply` 返回 `FX_KNOWN_ISSUE`。正确做法是换一个效果。确实要试时，先问使用者并请他保存工程，再带 `force:true` 调用。不要用 `ae_run_script` 绕过去。

## 2. 参数怎么定位

- 插件的参数名会随 AE 语言和汉化包变化，同一个参数在别的电脑上名字不一样。
- 一律用参数的 matchName，形如 `效果matchName-0004`。`ae_apply` 返回的参数表和 `ae_inspect` 里都有。
- 下面提到的参数后缀（例如 `-0109`）来自测试时的插件版本，用之前先用 `ae_inspect` 核对。

## 3. 效果加在哪一层

辉光、光线、体积光、热浪扭曲、转场这类会向外扩散的效果，直接加在文字图层上，画面会被图层边界裁成一个矩形。测试里出现过的有 Sapphire 的辉光和转场、FL Volumetrics、Heat Distortion。

做法二选一：
- 加在调整图层上；
- 先把文字预合成成合成尺寸，再加在预合成上。

## 4. 「内容」改不了的插件

有些插件的数值参数能用脚本改，但「内容」存在插件的内部数据里，脚本写不进去：

- Element 的场景（模型、挤出对象、材质）
- Particle Illusion 的发射器
- Universe 文字类效果的文字内容和字体
- Magic Bullet Looks 的调色风格
- Optical Flares 和 Sapphire 镜头光晕的光晕样式
- 各类曲线、渐变条

做法：请使用者在插件界面里选好一次，存成动画预设（.ffx）。以后用 `ae_apply preset:"…ffx"` 载入，再用 `ae_set` 改数值。载入预设这条路测试过，可以用。

## 5. 改了参数画面没变

这不代表控制不了。按顺序查：

1. 读回数值，确认写进去了。
2. 换一个参数。很多效果的各项默认是关的；转场类要改进度参数才有变化。
3. 调色、抠像、修复类效果，默认参数下画面本来就没有变化（名单里带 `nc` 标记的 332 个），要调参数或换合适的素材。

## 6. 几个具体做法

- **柔光加在有明暗层次的主体上**（例如金属质感的文字）：强度一高，明暗层次会被冲成一片白，文字也发虚。把阈值提高到只留高光，曝光降下来，柔光层放在文字图层下面。
- **Saber 沿文字轮廓发光**：「主体类型」（`-0109`）设为 3，「文字图层」（`-0132`）填文字图层的序号。文字图层可以是隐藏的，也可以是当遮罩用的。给「开始偏移」（`-0111`）和「结束偏移」（`-0008`）打关键帧，就是一道光沿轮廓走。
- **Text Anarchy 一套**：有 4 个效果加上时弹窗，其余默认输出全黑。要文字效果，用 AE 原生文字图层加别的效果。

## 7. 等待、内存和崩溃

- 有的效果第一次加上要等十几秒到一分多钟，这是首次加载，不是卡死。
- 出现 `AE_TIMEOUT` 时，先请使用者看 AE 里是不是有弹窗没关。
- 带插件的大场景渲染很吃内存。测试里一段约 3 秒的场景，AE 内存涨到 15—19 GB。渲染前后清一次缓存（AE 菜单「编辑 → 清理 → 所有内存与磁盘缓存」），长片分段渲染。
- AE 崩溃后重启，可能提示「某效果可能导致 After Effects 退出」，让你选禁用还是保持启用。这个由使用者自己决定，Claude 不替他点。

## 8. 交付

- 用了第三方插件的工程，对方没有装同版本的插件就看不到效果。交工程前把带插件的图层预渲染成视频层，或者只交成片。
- 交付前做两件事：
  1. `ae_check`：`effectIssues` 列出工程里已经用上的、测试时有问题的效果；`untestedEffects` 列出没测过的第三方效果。
  2. `ae_render_frames`：把用了第三方效果的画面渲染出来看。判断水印看的是画面上有没有多出东西，例如交叉线、铺满的字样、提示文字。

## 9. 没有测的

- 被归入旧版分类（`_Obsolete`、BCC 旧效果）的 252 个效果没有测。
- 默认画面无变化的 332 个，只确认了能加、能渲染、没有水印，没有逐个调参数。
- 插件自带的预设库能不能用脚本切换，没有测。
- 带插件的整片（几十秒以上）渲染稳定性，没有测。
- 脚本面板和扩展面板类的插件，不在这次测试范围里。
